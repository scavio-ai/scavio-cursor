# Changelog

## 0.1.0

Initial release. Purpose-built Cursor plugin - 12 skills, 4 commands, 1 rule,
and the hosted Scavio MCP server.

Not a port of the Claude Code package: setup guidance targets Cursor
(`~/.cursor/mcp.json`, `${env:...}` interpolation, Developer: Reload Window),
commands use Cursor's `name`/`description` frontmatter, and the `scavio-live-data`
rule has no Claude Code equivalent.
